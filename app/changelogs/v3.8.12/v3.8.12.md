## Overview

This release lists the subdocuments of a document automatically below its title and keeps the generated MCP client configuration on a fixed port.

## Changelogs

### Features

* List the subdocuments of a document directly below the title. The list follows the document tree and updates when documents are created, renamed, moved or deleted; click an entry to open it. It is hidden in zoomed, reference, history, publish and read-only views.
* Show the short application name in the macOS application menu.

### Enhancement

* Generate the MCP client configuration with the fixed 6806 port, so external AI clients no longer need to update their configuration after every restart.
