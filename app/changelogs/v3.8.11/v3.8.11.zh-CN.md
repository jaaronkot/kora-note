## 概述

Kora Note 是思源笔记的精简重塑版本，本版本是该分支的首个正式发布。应用完成更名与界面重排，移除了最占体积且用不到的功能，更新通道也已从上游项目改为指向本仓库。

## 变更记录

### 移除

* 移除图片 OCR 文字识别，包括 AI 辅助识别，不再随应用分发 PaddleOCR 与 ONNXRuntime 引擎
* 移除基于 Pandoc 的导入导出，包括随包分发的 Pandoc 二进制与过滤器
* 移除官方云账号与订阅体系，以及配套的云端资产源和云服务接口
* 移除收件箱
* 移除 iOS 端的应用内购买
* 移除云对象存储的同步探测与校验
* 移除设置页中的「集市」与「闪卡」标签页
* 移除每日笔记及其斜杠命令
* 移除顶栏的命令面板按钮、外观模式切换按钮以及每日笔记与闪卡按钮

### 改进功能

* 应用更名为 Kora Note，开屏页改为考拉形象，导出格式名同步更新
* 开屏页重做为静态图标、细进度条与版本号，跟随系统深浅色外观
* 顶栏精简为后退、前进与缩放，全局搜索与主菜单移入左侧停靠栏
* 关系图与反向链接面板移到左侧停靠栏，停靠栏快捷键按图标顺序编号
* 窗口标题只显示文档名与产品名
* 云同步按钮移到左侧停靠栏底端，紧贴设置齿轮上方
* 退出时的模态对话框改为角落浮层，并提供跳过同步的入口
* 面包屑中的文档图标与文档操作图标不再容易混淆
* 按 macOS 系统约定与 VS Code 重新整理快捷键，并在首次启动时迁移旧默认键位
* 官方网站、问题反馈与应用内更新通道全部指向本仓库
