## Overview

Kora Note is a trimmed-down, rebranded build of SiYuan Note, and this is the first release of the fork. The app is renamed and re-laid out, the heaviest unused features are dropped, and the update channel now points at this repository instead of the upstream project.

## Changelogs

### Removed

* Remove image OCR, including AI-assisted OCR. The PaddleOCR and ONNXRuntime engines are no longer shipped with the app.
* Remove Pandoc based import and export, including the bundled Pandoc binaries and filters.
* Remove the official cloud account and subscription system, together with the cloud asset source and cloud service endpoints.
* Remove the Inbox.
* Remove in-app purchases on iOS.
* Remove cloud object storage sync probing and validation.
* Remove the Marketplace and Flashcard tabs in Settings.
* Remove Daily Notes and its slash command.
* Remove the command panel button, the appearance mode switch and the daily note and flashcard buttons from the top bar.

### Enhancement

* Rebrand the app as Kora Note, with a koala boot screen and matching export format names.
* Rebuild the boot screen around a static logo, a slim progress bar and the version number, following the system light and dark appearance.
* Simplify the top bar to back, forward and zoom, and move global search and the main menu into the left dock.
* Move the linkage graph and backlinks panels to the left dock, and number the dock shortcuts by icon order.
* Show only the document name and the product name in the window title.
* Move the cloud sync button to the bottom of the left dock, directly above the settings gear.
* Replace the modal exit dialog with a corner overlay that offers to skip the sync.
* Distinguish the document icon and the document action icon in the breadcrumb.
* Reorganize the keyboard shortcuts after the macOS system conventions and VS Code, and migrate the existing default bindings on first launch.
* Point the official links, the feedback entry and the in-app update channel at this repository.
